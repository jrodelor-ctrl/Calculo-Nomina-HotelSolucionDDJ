# Informe de Entrega

## Título del proyecto

Cálculo de la Nómina de Empleados - Hotel Solución DDJ

## Descripción del problema

La empresa Hotel Solución DDJ requiere un sistema de nómina que permita gestionar diferentes tipos de empleados, calcular salarios, beneficios, deducciones y salario neto, aplicando programación orientada a objetos y buenas prácticas de desarrollo de software.

## Objetivo general

Desarrollar una aplicación local de escritorio que permita calcular la nómina de los empleados del Hotel Solución DDJ de forma organizada, confiable y visualmente agradable.

## Objetivos específicos

- Implementar una solución orientada a objetos.
- Aplicar principios SOLID y código limpio.
- Desarrollar una interfaz gráfica moderna y minimalista.
- Agregar inicio de sesión con roles de gerente y recurso humano.
- Implementar pruebas unitarias.
- Documentar el sistema y su metodología de construcción.
- Utilizar GitHub como evidencia del control de versiones.

## Características del sistema

- Aplicación local de escritorio.
- Inicio de sesión por roles.
- Registro de empleados.
- Cálculo de nómina.
- Validaciones de datos.
- Diseño visual elegante y fluido.

## Conclusión

El sistema desarrollado cumple con los requerimientos planteados en la actividad, incorporando programación orientada a objetos, buenas prácticas de codificación, pruebas unitarias, documentación y una interfaz gráfica adecuada al contexto de gestión hotelera.
